Cloud Service Demo

This sample page represents an application that could be hosted in the cloud.

One benefit of cloud computing is scalability: resources can be increased or decreased on demand to match traffic, so the application stays responsive without paying for unused capacity. This is often called elasticity.

a Docker image is a static, read-only template that acts as a blueprint, while a Docker container is a dynamic, running instance of that image

Kubernetes

Pod vs Deployment: A Pod is the smallest unit and runs one or more containers. A Deployment manages Pods and keeps the requested number of them running.

Service: Gives a stable address that routes traffic to a group of Pods, even as Pods are replaced.

Why more than one Pod: Handles more traffic and keeps the app available if one Pod fails.
